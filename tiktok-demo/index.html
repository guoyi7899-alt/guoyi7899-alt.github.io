TikTok for Developers

Sandbox posting demo

This is the public Direct Post walkthrough for the 極客創新有限公司 TikTok app. A reviewer authorizes with Login Kit, returns to the registered callback, and posts a short private video.

  1. Step 1 Authorize

    Continue with TikTok. The public client key comes from the Worker. The client secret never leaves the Worker.

  2. Step 2 Return

    TikTok redirects to the registered callback. That page exchanges the one-time code on the Worker and shows only the open ID, scope, and expiry.

  3. Step 3 Post

    Choose the sample video and Only me, then post. The Worker sends a sandbox Direct Post with PULL_FROM_URL and SELF_ONLY.

Authorize with TikTok

Login Kit uses user.info.basic and video.publish. The redirect URI is exactly https://geek-innovation.com/tiktok-demo/callback/. Use a private sandbox test account.

What the reviewer can check

Authorize URL
https://www.tiktok.com/v2/auth/authorize/
Scopes
user.info.basic,video.publish
Redirect URI
https://geek-innovation.com/tiktok-demo/callback/
Worker
https://geek-innovation-api.guoyi4491.workers.dev
Token exchange
The callback sends { code, redirect_uri } to POST /oauth/token. A success body is only ok, open_id, scope, expires_in, and token_type.
Direct Post
The callback sends the caption, SELF_ONLY, and the video URL to POST /publish. The Worker is expected to call TikTok’s video init endpoint. If that route is missing, the page says so and does not pretend the video was posted.

This demo does not create an account on geek-innovation.com. TikTok login is only the Login Kit step for the sandbox post. See the Privacy Policy and Terms of Service.
